Cheat Sheet — สูตรสถิติที่ใช้บ่อย

ค่ากลาง (จากข้อมูลดิบ)

  • ค่าเฉลี่ยเลขคณิต: \(\bar{x}=\dfrac{\sum x_i}{n}=\dfrac{\sum fx}{N}\)
  • มัธยฐาน (n คี่): ค่าตรงกลาง; (n คู่): ค่าเฉลี่ย 2 ค่าตรงกลาง
  • ฐานนิยม: ค่าที่ซ้ำมากที่สุด

การวัดตำแหน่ง (จากข้อมูลดิบ — ยัง IN)

  • ควอไทล์: \(Q_1\) = ค่าตำแหน่งที่ 25%, \(Q_2\) = มัธยฐาน, \(Q_3\) = ค่าตำแหน่งที่ 75%
  • เดไซล์: \(D_k\) = ค่าตำแหน่งที่ \(10k\%\)
  • เปอร์เซ็นไทล์: \(P_k\) = ค่าตำแหน่งที่ \(k\%\)
  • ตำแหน่ง \(= \dfrac{k}{100}\times n\) (แล้วปัด/ interpolate ตามวิธี)

การกระจาย (จากข้อมูลดิบ)

  • พิสัย: \(R = x_{\max}-x_{\min}\)
  • ส่วนเบี่ยงเบนควอไทล์: \(Q.D. = \dfrac{Q_3-Q_1}{2}\) — IN
  • ความแปรปรวน (population): \(\sigma^2 = \dfrac{\sum(x_i-\bar{x})^2}{N}\)
  • ความแปรปรวน (sample): \(s^2 = \dfrac{\sum(x_i-\bar{x})^2}{n-1}\)
  • ส่วนเบี่ยงเบนมาตรฐาน: \(\sigma = \sqrt{\sigma^2}\) หรือ \(s=\sqrt{s^2}\)

การกระจายสัมพัทธ์

  • สัมประสิทธิ์การแปรผัน (CV): \(CV = \dfrac{S.D.}{\bar{x}}\times 100\%\) — IN
  • OUT: สัมประสิทธิ์ของพิสัย, สัมประสิทธิ์ของ Q.D., สัมประสิทธิ์ของ M.D.

ค่ามาตรฐาน + การแจกแจงปกติ

  • z-score: \(z = \dfrac{x-\mu}{\sigma}\)
  • พื้นที่ใต้โค้งปกติมาตรฐานระหว่าง \(z=0\) ถึง \(z=a\) = ค่าจากตาราง
  • กฎประจำกฎ: ประมาณ 68% อยู่ใน \(\mu\pm\sigma\), 95% ใน \(\mu\pm 2\sigma\), 99.7% ใน \(\mu\pm 3\sigma\)
  • เปอร์เซ็นไทล์จาก z: \(P = 50 + (\text{พื้นที่ } z)\times 100\) ถ้า \(z>0\)
